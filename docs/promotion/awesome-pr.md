## PR 内容模板（每个列表微调）

**PR 标题：**
Add TrustLens: an open-source trust benchmark / leaderboard for MCP servers

**PR 描述：**
Adds [TrustLens](https://github.com/hyqzz/trustlens) — an open-source trust benchmark for MCP servers and agent skills.

It runs real servers in a zero-credential sandbox (90s handshake, smart probes generated by DeepSeek-V4 Flash, real-model tool-call checks) and publishes a 0–100 trust score with all evidence committed as JSON (git history is the audit log). Live bilingual leaderboard: https://trustlens.icodestar.net/

It evaluates servers rather than being a server itself, so it fits best as a "community / tools" entry if the list has such a section.
