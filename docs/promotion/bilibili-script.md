# B站 / 视频号 视频脚本

> 短视频是 2026 年技术内容分发效率最高的渠道之一。这份脚本 3 分钟可讲完核心叙事，可拆成 1 条横屏长视频或 3 条竖屏切片。
> 数据核验：录制前对照 https://trustlens.icodestar.net/ 复核数字。

## 脚本（3 分钟版）

**镜头 0（0:00–0:05）钩子**
画面：一个人点"安装 MCP 服务器"，下一秒屏幕变红崩溃。
旁白："装 MCP 服务器就像开盲盒——你根本不知道里面是能用的，还是装完就崩的。"

**镜头 1（0:05–0:25）问题**
画面：数据滚动（6 万+ 服务器 → 66% 有安全问题 → 88% 试点死在上生产前）。
旁白："MCP 生态两年不到，公共服务器已经 6 万多个。跨注册表研究显示 66% 存在安全问题；88% 的企业 Agent 试点，不是死在模型不行，是死在没人敢保证工具靠谱。有应用商店，没有大众点评。"

**镜头 2（0:25–1:10）实测**
画面：脚本化演示评测流水线（隔离环境 → 握手 → 安全扫描 → 智能探针 → 出分）。
旁白："所以我做了一件事：把每个服务器放进隔离沙箱，不配任何凭证，按文档标准方式启动，90 秒内完成握手才算能用。功能维度不是静态估算，是用 DeepSeek 智能探针按工具的真实场景生成参数、真实调用。结果："

画面：等级分布柱状图 A7/B14/C20/D3/F68。
旁白："112 个去重的真实服务器，约六成是 F——装完连协议握手都完不成。失败原因以启动即崩溃、缺 API 凭证为主，每台的失败审计在详情页可查。"

**镜头 3（1:10–1:40）反直觉**
画面：ifconfig-mcp 满分卡片 vs filesystem C 级 vs desktop-commander C 级。
旁白："最反直觉的是：唯一满分是名不见经传的 ifconfig-mcp；官方 filesystem 只有 C 级、网红 desktop-commander 也只有 C 级。GitHub 星标代表被看到，不代表能用。"

**镜头 4（1:40–2:20）价值 + 透明**
画面：GitHub 仓库 JSON 文件 + git log。
旁白："我把评测做成了开源项目 TrustLens，全部数据以 JSON 提交在仓库——git 历史就是审计日志。做信任生意，自己先得透明。排行榜中英双语、每周自动更新，装 Agent 工具之前先查个分。"

**镜头 5（2:20–3:00）CTA**
画面：排行榜 URL 放大 + 仓库。
旁白："地址：trustlens.icodestar.net。仓库在 GitHub，搜索 TrustLens 智码星就行。数据每周刷新，欢迎来拍砖——我准备了三个问题：装 MCP 前你会查评分吗？90 秒握手的标准合理吗？权重该调整吗？评论区见。"

## 切片方案（竖屏 3 条，各 30–45s）

1. **钩子条**：镜头 0+1（"开盲盒"+"66% 有安全问题"）
2. **数据条**：镜头 2（约六成 F + 失败原因），字幕大字突出"60%"
3. **反直觉条**：镜头 3（官方 filesystem 只有 C 级），标题"热门≠靠谱"

## 制作与发布

- 配音：可用 TTS 或自己录，语气"平静讲数据"比激情更重要（专业感）
- BGM：无或极轻；字幕全程开启
- 发布：B站（科技区/编程）、视频号、抖音同步；标题如「实测 112 个 MCP 服务器，约六成根本没法用」
- 置顶评论放排行榜链接 + 仓库
- 每周红黑榜可做成 45 秒"本周 MCP 红黑榜"系列，固定片头
