## 排版结构（正文）

**导语（加粗，2 行内）：**
> MCP 生态有 6 万+ 公共服务器，但没有任何质量信号。我花了一个月实测 112 个去重的真实服务器——约六成装完根本没法用。

**正文按掘金文结构分 6 段，公众号排版的 4 个要点：**
1. 每段小标题用"一、二、三"大字号加粗，段与段之间空一行
2. 数字表格保留（等级分布表），但表格在手机端要精简为 5 行以内
3. 引用"热门≠靠谱"那句话单独成块（可用引用样式）
4. 命令块 `python -m trustlens check <server-name>` 保留，读者可本地复现

**结尾引导（必放）：**
```
—

这是一个会长期做下去的开源项目（Apache-2.0），数据每周自动更新：
• 排行榜：https://trustlens.icodestar.net/
• 仓库：https://github.com/hyqzz/trustlens

觉得有用的话，点个「在看」，或转发给正在搭 Agent 的朋友。

也可以在后台回复「进群」，一起聊 Agent 工具生态。
```
