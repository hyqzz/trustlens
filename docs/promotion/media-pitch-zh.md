## 投稿邮件模板

**主题：**
实测 112 个真实 MCP 服务器：60% 装完无法使用 —— 开源"Agent 工具质检局"TrustLens 数据首发

**正文：**

您好，

分享一个开源项目的数据，可能对贵号读者有参考价值：**TrustLens（智码星 ICodeStar）**，一个给 AI Agent 工具做质检的信任基准，今天已上线中英双语排行榜。

**核心数据**（全部为自动化实测，非估算）：
- 从 npm/PyPI 抓取真实发布的 MCP 服务器，去重后实测 **112 个**：A 级仅 8 个（7%），**F 级 67 个（60%）——按文档 `npx -y <pkg>` 装完、不配任何凭证，90 秒内连协议握手都完不成**
- 失败原因（按 stderr 审计）：启动即崩溃 49 / 缺 API key 崩 14 / 包解析问题 2 / 真·挂起 1
- **"热门≠靠谱"**：唯一满分是名不见经传的 ifconfig-mcp（100）；官方 filesystem 仅 C 级（70）、desktop-commander 仅 C 级（72）
- 110 个 Agent Skills 三维评测（结构/安全/LLM 可执行性）：A:18 B:81 C:11

**为什么有报道价值**：
- MCP 生态 2 年内已有 6 万+ 公共服务器，但**没有任何质量信号**——这是第一次有人把"装之前先查分"做成公开数据
- 功能维度用 **DeepSeek-V4 Flash 智能探针真实调用**（按工具场景生成参数、安全护栏清洗），**"同一个工具，模型到底能不能用起来"的数据此前无人发布**
- 全部数据以 JSON 提交在仓库，**git 历史即审计日志**，可核验

**可用素材**：
- 排行榜（中英双语）：https://trustlens.icodestar.net/
- 数据卡：https://trustlens.icodestar.net/og-card.png
- 仓库：https://github.com/hyqzz/trustlens （Apache-2.0，零依赖 Python）
- 需要原始 JSON、失败进程 stderr 样本、或按贵号角度的补充数据，随时联系

**关于我**：15 年软件工程师，现全职做 AI 应用基础设施（智码星 ICodeStar）。这个项目长期维护，数据每周自动更新。

期待回复，谢谢！

**附：给记者的三句话速览**
1. 60% 公共 MCP 服务器装完无法使用（实测 112 个，零凭证、90 秒握手）
2. 热门≠靠谱：官方 filesystem 只有 C 级，唯一满分是冷门 ifconfig-mcp
3. 全部数据公开在 GitHub，git 历史即审计日志，可复核

## 发送建议

- 逐个媒体发，主题按"媒体名 + 数据"个性化（如"InfoQ：一个 0–100 的 Agent 工具信任分怎么算"）
- 发邮件后 3–5 个工作日无回复可跟进一次（附上最新榜单截图）
- 配合 D-Day：媒体稿最早 D-Day 当天 9:00 后发（避免和首发文抢注意力），或 D+2 作为"数据二波"
