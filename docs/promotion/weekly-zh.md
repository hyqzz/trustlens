# 每周 MCP 红黑榜 · 中文模板（周更运营）

> 每周一评测结果自动上线后，用本模板快速产出短内容。数据来源：https://trustlens.icodestar.net/（对照在线榜单填数）。
> 分发：掘金 + 公众号 + 即刻/微博 + V2EX（择一）。每周一固定发，形成订阅心智。

## 填写说明（每周 10 分钟）

1. 打开排行榜，记下：本周新增服务器数、新增 A/F 数、变动最大的 3 个服务器
2. 填下面模板的【】处
3. 按渠道裁剪：公众号/掘金用全文，微博用"红榜/黑榜"两行

---

## 模板

**标题：**
本周 MCP 红黑榜：新增【N】个服务器，【X】个 F 级翻车

**导语：**
TrustLens 每周自动复测 112+ 个真实 MCP 服务器，本周更新结果如下（数据时间：【日期】）。

**本周红榜（能用且靠谱）：**
1. 【服务器 A】——【分数】分，【一句话亮点，如"文档清晰、握手秒过"】
2. 【服务器 B】——【分数】分，【亮点】
3. 【服务器 C】——【分数】分，【亮点】

**本周黑榜（翻车现场）：**
1. 【服务器 D】——【分数】分，【失败原因，如"缺 API key 直接崩"】
2. 【服务器 E】——【分数】分，【失败原因】
3. 【服务器 F】——【分数】分，【失败原因】

**一句话点评：**
【如"本周新增的 N 个里，一半仍是 F 级——生态还在野蛮生长"】

**完整榜单（中英双语，可搜索/筛选）：** https://trustlens.icodestar.net/
**仓库（Apache-2.0，数据全公开）：** https://github.com/hyqzz/trustlens

**下期预告 / 求互动：**
你希望我们下周重点复测哪一类服务器？（评论区点名）

---

## 复用提示

- 红榜别只放高分，放"最近有用户在用且实测稳定"的，建立"我们真的在用"的信誉
- 黑榜失败原因必须写清楚（按 stderr 审计），否则会被当成"抹黑"
- 同一周的内容可派生：公众号全文 + 微博两条 + 即刻一条 + B站 45s 视频脚本（见 bilibili-script.md）
